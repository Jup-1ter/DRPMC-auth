# Особенности сервера авторизации
## Мир
Мир представляет собой область 16x16 чанков, огороженную границей мира. Сложность сервера мирная (голод отключён). Течение времени остановлено, включая смену погоды. Если игрок покидает стартовый чанк, то получает перманентный бан за использование читов
## Игроки
Игроки появляются на координатах 0 0 0 в небольшой коробке из блока барьера в режиме приключений. Данные игроков (инвентарь, местоположение, достижения, статистика и т.д.) не сохраняются. Игроки скрыт друг от друга
## Команды
На сервере авторизации доступны только команды, связанные с авторизацией: register, login
### /register <пароль>
Используется для регистрации нового аккаунта, если аккаунта с таким ником ещё не существует<br/>
*Вариации: /reg, /r*
### /login <пароль>
Используется для входа в существующий аккаунт<br/>
*Вариации: /log, /l*
## Права
**НИКОГДА** не следует выдавать повышенные права игрокам на сервере авторизации, т.к. действия на сервере авторизации ничем не ограничены
## Чат
Сообщения о подключении/отключении игроков выключены. Игроки не могут отправлять ничего в чат, кроме команд
